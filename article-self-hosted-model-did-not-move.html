Self-hosted moved inside the firewall. The model did not move with it.

What moves inside is the service that runs the agents. The model stays where it was.

On Nov 12, 2026, Anthropic put self-hosted Claude Managed Agents into private beta. The headline is easy to misread. It sounds like Claude itself now runs inside a company's own systems. It does not. What moves inside is the service that runs the agents. The model stays where it was, and every model call still travels out to a provider the customer picks. The distinction matters, because self-hosted now means at least two different things, and the same month produced a clear example of each.

What Anthropic actually shipped

Managed Agents is Anthropic's service for long-running AI agents, the kind that fix broken builds, test releases, triage alerts, and work through backlogs. It launched as a hosted service in April 2026. In May 2026, Anthropic added self-hosted sandboxes, so an agent's tool execution could run on customer systems while Anthropic still ran the agent itself. The Nov 12 step moves the rest of the service inside as well. The customer runs three pieces: the cma-server, which serves the Managed Agents API, runs the agent loop, and stores agents, sessions, and history; a PostgreSQL database, version 16 or later, which holds that history; and workers that run the agents' shell and file tools inside sandboxes the customer controls. Anthropic's docs state that it has no remote access to a customer's self-hosted server or its logs.

What does not move is the model. Each time an agent asks Claude something, the request goes to an inference provider. Anthropic's Claude API is the default. The alternatives named in the docs are Amazon Bedrock, Claude models on Google Cloud, Microsoft Foundry, or the customer's own model gateway. Anthropic's data and access docs add a sentence that should not be skipped: each model call carries the conversation so far, including prompts, tool inputs, and tool results. Session history can now live in the customer's own database, and credentials can stay in-house, but the content of each call still leaves the network unless the customer routes it to a gateway it controls.

The self-hosted edition is also not a feature-for-feature copy of the hosted service. Anthropic's docs list hosted features that are not available on the self-hosted server, including cloud environments, the Files API, webhooks, scheduled deployments, dreams, prebuilt document skills, and vault credentials for MCP OAuth, plus full multiagent orchestration, which is limited to coordinator-type setups. Web search and web fetch stay off until explicitly enabled. Nothing migrates from the hosted service. One tenant runs per deployment. The customer operates and secures the server, the database, and the sandboxes, and installs each release itself. Access runs only through an Anthropic account team, for eligible organizations. Anthropic has published no price and no general availability date. A private beta open only to eligible organizations, with no price and no date, is a controlled test, not a product launch.

The other meaning of self-hosted

The same month produced the other meaning of self-hosted. At the AI Engineer NYC conference on Oct 13, 2026, David Abitbol, who leads AI operations at Revolut, described how the fintech made self-hosted open-weight GLM models the default coding stack for roughly 2,000 engineers, running on about 56 NVIDIA B200 GPUs. Coverage of the talk in early November reported a blended inference cost near $0.30 per million tokens and inference costs roughly 90 percent below the prior commercial mix, plus reported productivity gains of about 60 percent less coding time and 70 percent shorter task-to-merge lead time. Those figures are company-reported, not independently audited, and the coverage does not isolate the model change from other causes. The model version is also inconsistent across secondary coverage, with GLM-5.3 and GLM-4.5 both named, while the primary post names only GLM. Frontier tools, including Claude Code and Codex, remain available for exceptions. The point that holds across the coverage is the architecture: Revolut downloads open model weights and runs inference on infrastructure under its control. The model itself moved inside. That is different from Anthropic's beta, where the service moved inside and the model did not.

Both stories are real, and they answer different questions. Anthropic's beta answers: can the agent service, its history, and its credentials live inside our perimeter, under our operation? Revolut's setup answers: can the model itself run on hardware we control, with our code staying on our systems? A buyer who hears self-hosted and assumes both answers are yes will be wrong about at least one of them.

Five questions to ask before calling any setup self-hosted

  1. Where do model calls go? Name the provider for every call, including the default. If the answer is a vendor API, the model is hosted, whatever else is self-hosted.
  2. What leaves the network on each call? Prompts, tool inputs, tool results, and conversation history all travel with the call unless the routing says otherwise. Get that in writing.
  3. Who holds the history and the credentials? In Anthropic's beta, the customer holds both, in its own database and its own systems. In a hosted service, the vendor holds them. The difference decides who can audit, retain, and delete the record.
  4. What is missing compared with the hosted version? Feature gaps, disabled tools, and migration limits change what a team can actually run. Read the differences page before planning a move.
  5. Who operates and patches it? Self-hosting moves the work, not just the data. The server, the database, the sandboxes, and each release are the customer's job now, including security updates on the vendor's timetable.

What to watch

Whether Anthropic's beta opens wider, publishes pricing, and closes the feature gaps, and whether more large engineering teams follow Revolut's path of running open-weight models as the default with frontier tools kept for exceptions. Self-hosted is no longer one claim. It is a split, and the useful question is always the same: which part moved, and which part did not?
